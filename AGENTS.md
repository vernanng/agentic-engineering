# Agentic Engineering — real app, local first

- Root is product: [src/main.rs](src/main.rs) (Rust app, single binary `loop-app`), [src/bin/client.rs](src/bin/client.rs) (detached CLI `client`), [static/index.html](static/index.html) (UI), [tests/gate.rs](tests/gate.rs) (gate), [Cargo.toml](Cargo.toml), [deploy.sh](deploy.sh), [.github/workflows/cd.yml](.github/workflows/cd.yml). Local only (`http://localhost:8000`) — no cloud without an explicit ask. No Docker.
- Fast path: `cargo test` (gate, must pass) → `./deploy.sh` (only from `main`: gate → `cargo build --release` → DB backup to `backups/` → binary to `releases/loop-app-<git-sha>` → restart → health-check `GET /api/task-types` → auto-rollback to previous binary on failure). Logs: `tail -f loop-app.log`. Stop: `kill "$(cat .loop-app.pid)"`.
- Bare run: `cargo run --release` (no gate/rollback). Env: `PORT` (8000), `HOST` (localhost), `LOOP_DB` (`loop.db`), `LOOP_TOKEN`, `OPENROUTER_*`, `JEV_MODEL`, `JEV_MOCK`, `DEEPSEEK_FLASH_MODEL`, `OPENROUTER_API_BASE` (test override). Secrets via `.env` only (gitignored, see [.env.example](.env.example)); [deploy.sh](deploy.sh) sources it, bare `cargo run` does not.
- Git: branch per task (never code direct on `main`); merge to `main` first, then deploy. Push to `main` triggers the same [deploy.sh](deploy.sh) on the self-hosted runner ([cd.yml](.github/workflows/cd.yml), macOS). Never push without an explicit ask.
- Loop: build `in` >> `near` >> `out` (out last; never start a new task type in `out`). Promote after 3 consecutive clean `in` runs / 5 clean `near` runs (manual Promote click; `force:true` bypasses). `out` failure halts the run, writes an `alert` audit entry, and demotes the task type to `near`. Guardrails: 60s run/decision timeout, template allowlist only (`summarize|classify|report|incident|news`), 1 MB body cap.
- Tasks: edit `templates()` in [src/main.rs](src/main.rs) — steps are `(name, confidence, risky)`. Keep `run_step(step_name, text, confidence) -> (output, confidence, usage)`; input containing `FAIL` always errors (failure-path test hook).
- Executor: `run_step()` calls OpenRouter when `OPENROUTER_API_KEY` is set, else a local stub (no spend). Tiers: cheap (`cheap_model`) for confidence ≥ 0.9, main mid-range, escalation below live `conf_threshold` (default 0.7). Real `usage` (tokens, cost) is stored on the step when present; without it the chars/4 proxy with cost 0 is kept. Model must return JSON `{"output", "confidence"}`; any call/parse failure errors so pause/alert handling engages. Config is read live (`get_config()`).
- API (`/api/*`, JSON): `GET /api/task-types`, `POST /api/task-types`, `POST /api/task-types/:id/mode`, `POST /api/task-types/:id/promote`, `GET /api/runs` (latest 50), `POST /api/runs`, `GET /api/runs/:id`, `POST /api/runs/:id/decide`, `POST /api/runs/:id/control` (`pause`/`resume`/`kill`), `DELETE /api/runs/:id` (finished only), `GET /api/audit` (latest 100), `POST /api/triggers/:task_type_id`, `POST /api/events` (4xx/5xx fast path, else Jev-gated), `GET/POST /api/items` + `POST /api/items/:id/vote`, `GET/POST /api/weights`, `GET /api/executions`, `GET /api/tools`, `GET/PUT /api/config`, `GET/POST /api/crons` + `DELETE /api/crons/:id`, `GET/POST /api/pages` + `POST/DELETE /api/pages/:id`, `GET/POST /api/proposals` + `POST /api/proposals/:id/decide`, `POST /api/factories` (= `loop-app --init-factory f.json`; always starts `in`). Jev commands live in `prompt_engineering/jev/` (`relevance|worth-attention|importance|same-story|hfs`); no key fails closed, `JEV_MOCK=1` is the labelled dev mock. `news` runs are deterministic sweeps (gather→gate→dedupe→rank→present, top 7); feed reads are capped at 5 MB. On boot `queued` runs resume, mid-flight runs are killed. Disabling the `coding` slice makes `run_step()` error.
- Data: one SQLite file `loop.db` (same schema as the Python era; old DBs are migrated in place with `tokens`/`cost` columns). Never edit the DB by hand; [deploy.sh](deploy.sh) backs it up before every deploy. Pre-Rust backups: `backups/loop-local-pre-rust.db`, `backups/loop-docker-pre-rust.db`.
- Gate: `cargo test` boots the real binary on port 18099 with a temp DB, mocks OpenRouter + Jev locally (no network, no spend), and covers all modes, promotion, TSF, triggers, the sweep, the CLI, and reading a copy of the real `loop.db`.
- shortcut: with a key set, run inputs are sent to OpenRouter/third-party models — never send confidential input until a data policy is chosen.
- shortcut: [src/main.rs](src/main.rs) uses one SQLite connection + lock for all runs; upgrade to per-thread connections when parallel `out` runs matter.
- shortcut: cron lives in this process and dies with it; `next_run_at` is durable in SQLite, so a restart delays, never loses.
